# 潜渊症 Mod 管理器 v0.4.0

自 v0.2.7 以来的全部改动整合版。新增四个功能模块，另修了若干问题。

## 新增：存档页

- 看清**每个存档当时启用了哪些 mod**（直接解析 `.save`，gzip + UTF-16LE 前缀）：
  按加载顺序列出，并标出哪些 mod 现在游戏里已经没有了；单机 / 多人分开列
- 找出**能用来实现这个存档的合集**：标出「完全一致」或「某某合集完全覆盖了它」，
  并把合集里多出来的 mod 逐个列出来（实测这些"多出来的"基本都是 LuaCs 这类客户端 mod ——
  **游戏从不把纯客户端内容包写进存档**，所以"完全一致"几乎不成立）
- 一键：**应用那个合集** / **按存档启用**（用存档的 mod 列表新建合集并应用）/ **存为新合集**

## 新增：同步到游戏

游戏只在你**自己在 mod 列表里按更新键**时才装工坊更新（实测能拖好几天）；
这个按钮把「Steam 已经下载好、游戏还没装」的更新直接装进 `WorkshopMods\Installed`。

- 顶栏只在**真有**待同步的 mod 时出现，带数量；卡片上也会标「待同步到游戏」
- 先列出待同步的 mod 和体积（版本变化写成 `游戏里 v1.110 → Steam v1.111`），确认后才动手
- 与游戏内更新等价，但**不会让 Steam 把整包重下一遍**（实测少下 59 MB 那种）
- 已下架的 mod 不算「待同步」（游戏本来就不会装它们），会单列出来指到「备份已下架的」

## 新增：浏览工坊

在管理器里直接搜索 / 排序 / 分类浏览创意工坊：

- **关键词搜索**、5 种排序（最热门 / 趋势 / **最近更新** / 最新发布 / 口碑最好）、
  **23 个分类标签**（可多选，多个是「同时满足」）、翻页
- 点卡片看**详情**：封面 + **截图画廊**（点缩略图切换）、订阅/收藏/浏览/创建日期、分类标签，
  以及**工坊描述的完整排版**
- **描述语言**：配了 Steam Web API Key 时直接拿**作者写的中文描述**（不是机翻）；
  作者没写中文的条目会给一个「**翻译成中文**」按钮（免费接口 MyMemory，结果会缓存）
- **下载交给 Steam**：点「在 Steam 里打开」→ 在 Steam 客户端里点「订阅」→
  回到管理器点顶栏「同步到游戏」装进游戏

> ⚠️ 这个页面的数据来自 Steam 官方接口，所以：① 需要填 **Steam Web API Key**
> （[申请地址](https://steamcommunity.com/dev/apikey)，域名随便填 localhost，在「设置」里填入）；
> ② **必须能访问 Steam** —— 国内一般要先开加速器，否则会提示「连不上 Steam」。

## 新增：合集导入 / 导出（联机分享）

- 导出 **`.xml`** —— 游戏原生格式，**对方不用装本管理器**，丢进 `Barotrauma\ModLists\` 就能在游戏里选
- 导出 **`.json`** —— 用本管理器的朋友导入时信息最全
- **复制成文本** —— 贴聊天里，每个工坊 mod 一行带链接，点开就能订阅
- 导入认这三种（选文件或**直接粘贴**）：哪怕朋友只发来一串工坊 id 也能认出来，
  会自动补上 mod 名字并列出**本机还没有的**
- **未订阅清单**：合集里有本机还没有的 mod 时，编辑器顶上出现「只看未订阅 N」筛选，
  每一行都能点「**去订阅**」直接打开那个 mod 的工坊页面
- 重名合集自动加序号，**绝不覆盖已有合集**

## 修复与改进

- **应用合集后界面立刻刷新**：以前点一次「应用到游戏」其实已经写进配置了，
  但界面还显示旧状态，看起来像没生效，会让人再点一次
- **`config_player.xml` 备份只留一个**：以前每次应用都生成一个带时间戳的备份，
  应用几十次后游戏根目录里全是这些文件；现在固定覆盖同一个 `config_player.xml.bak`，
  并会在下次应用时把旧的清理掉
- **本地 mod 在 `config_player.xml` 里必须写成游戏的相对形式**（`LocalMods/<文件夹>/filelist.xml`）：
  写绝对路径游戏认不出来，表现是"mod 明明启用了进游戏却没生效"
- 截图 / 描述读取失败时不再静默退回旧缓存（写缓存失败不该丢掉刚取到的新数据）

## 安装

下载 `barotrauma-mod-manager-setup-0.4.0.exe` 双击安装（**按用户安装，不需要管理员权限**）。
已经装过旧版本的，启动后会收到更新提示，点两下即可升级。

## 已知限制

- 「浏览工坊」必须配 API Key + 能访问 Steam，否则只能看到提示
- 机器翻译只用于作者没提供中文描述的条目，专有名词可能不准
- 「同步到游戏」时如果游戏正在运行且该 mod 里有已加载的 `dll`（比如 LuaCs），文件会被系统锁住，
  界面会提示「文件被占用 —— 关掉游戏后重试」
