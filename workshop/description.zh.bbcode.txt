[h1]潜渊症 Mod 管理器[/h1]

管理本地 mod 和创意工坊 mod 的 Windows 桌面程序。它不是游戏内的 mod，是一个单独的程序。

平时进游戏前要一个个勾 mod、手动排顺序；过段时间回来，某个 mod 被作者删了、存档打不开；工坊悄悄更新了，本地还是旧的。这个工具把这些摊开给你看。

[h2]它能做什么[/h2]

[list]
[*]合集：直接读写游戏自己的 ModLists\*.xml。拖拽排序，一键应用，写回 config_player.xml 之前自动备份。
[*]导入导出：能导出成游戏原生 xml（别人不装这个程序也能直接用）、带名字和链接的 json、或者直接贴群里的一段文本。导入时会自动补上 mod 名字，并列出你还没订阅的，点一下打开工坊页面。
[*]本地 mod 和工坊版本对比：看出哪个更新，一键用工坊版覆盖本地版，或者把它复制成一份新的本地 mod。覆盖前先留快照。
[*]同步到游戏：Steam 已经下好的更新直接装进游戏，不让它整包重下。
[*]存档：看每个存档当时启用了哪些 mod，以及哪个合集能把它还原出来。
[*]备份：一键把工坊里的 mod 全存到本地；单个 mod 也能随时打快照、回滚。
[*]分类标签：按关键词自动分类，也能自己建标签。一个 mod 可以挂多个，点标签就筛选。
[*]封面、搜索、来源筛选、排序。
[/list]

[h2]怎么装[/h2]

[list]
[*]订阅这个条目，等 Steam 下载完。
[*]在 Steam 里右键「潜渊症」→ 管理 → 浏览本地文件（打开的是 steamapps\common\Barotrauma），往上退一级到 steamapps，再进 workshop\content\602960\3817971486。
[*]运行 setup.cmd，或者直接双击同目录里那个 setup.exe。
[/list]

装完桌面会有快捷方式。按用户安装，不弹 UAC。

没开过游戏也没关系，文件就在上面那个 Steam 目录里。如果你已经启动过游戏，同一份文件也会被复制到 %LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\3817971486，两个位置都能用。

[h2]更新[/h2]

Steam 更新这个条目之后，打开一次已经装好的程序就行：它会发现新版，点一下自己完成升级并重开。不用去找安装包。

[h2]它是工具，不是 mod[/h2]

装完不要把它启用进 mod 列表，也不要挂在服务器上。

[h2]关于读写和联网[/h2]

读取：你指定的游戏目录、当前用户的 mod 和配置目录、Steam 的清单文件。

写入：只写你指定的游戏目录，以及 %APPDATA%\潜渊症Mod管理器。

联网：只用 Steam 的公开工坊接口和页面。这个版本不需要 Steam Web API Key，也没有「浏览工坊」。

不枚举进程、不写注册表、不读浏览器和凭据，没有遥测，不需要管理员权限。这些是本程序的代码约束，不是操作系统沙箱。

[h2]其它[/h2]

GitHub 上还有一个功能更多的版本，带「浏览工坊」（在程序里搜索 mod、看截图和描述）和工坊下架检查。这两个功能用的人少，我没法确认在别人机器上都正常，所以没放进这个条目。想试的话去 github.com/kudachou/barotrauma-mod-manager/releases，安装包文件名不带 workshop 的那个是完整版，需要你自己申请一个 Steam Web API Key。

有问题写在评论里也行。
