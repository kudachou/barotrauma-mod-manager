[h1]Barotrauma Mod Manager[/h1]

A Windows desktop app for managing your local and Workshop mods. It is not an in-game mod, it is a separate program.

You know the routine: tick every mod by hand before you play, drag them into order, come back a month later and a mod has been deleted by its author so your save won't open, or Steam updated something and your install is still on the old copy. This tool lays all of that out in front of you.

[h2]What it does[/h2]

[list]
[*]Collections: works on the game's own ModLists\*.xml. Drag to reorder, apply in one click. config_player.xml is backed up before it is written.
[*]Import and export: export as the game's native xml (usable by people who do not have this app), as json with names and links, or as plain text you can paste into chat. Importing fills in the mod names, lists the ones you have not subscribed to, and gives you a link to each Workshop page.
[*]Local vs Workshop: see which copy is newer, overwrite the local one with the Workshop version, or copy it out as a new local mod. A snapshot is taken first.
[*]Sync into game: install updates Steam already downloaded, instead of letting Steam pull whole packs again.
[*]Saves: see which mods a save had enabled, and which collection reproduces it.
[*]Backups: copy every Workshop mod to your machine in one go. Individual mods can be snapshotted and rolled back at any time.
[*]Tags: automatic sorting by keyword, plus your own tags. A mod can carry several, click a tag to filter.
[*]Covers, search, source filters, sorting.
[/list]

[h2]Installing[/h2]

[list]
[*]Subscribe to this item and let Steam finish downloading.
[*]In Steam, right-click Barotrauma, Manage, Browse local files (this opens steamapps\common\Barotrauma). Go up one level to steamapps, then into workshop\content\602960\3817971486.
[*]Run setup.cmd, or just double-click the setup.exe next to it.
[/list]

A desktop shortcut is created when it finishes. It installs per user and does not ask for admin rights.

You do not need to have launched the game. The files are already in that Steam folder. If you have launched it, the same files also get copied to %LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\3817971486. Either location works.

[h2]Updating[/h2]

After Steam updates this item, just open the app once. It notices the new version, and one click upgrades and reopens it. No hunting for installers.

[h2]It is a tool, not a mod[/h2]

Do not enable it in your mod list and do not put it on a server.

[h2]What it reads and writes[/h2]

Reads: the game folder you point it at, your mod and config folders, and Steam's manifest files.

Writes: only the game folder you chose, plus %APPDATA%\潜渊症Mod管理器.

Online: only Steam's public Workshop API and pages. This edition needs no Steam Web API key and does not include Browse Workshop.

No process enumeration, no registry writes, no browser or credential access, no telemetry, no admin rights. Those are limits in our code, not an OS sandbox.

[h2]Elsewhere[/h2]

There is a fuller version on GitHub with Browse Workshop (search mods, view screenshots and descriptions inside the app) and a delisted-mod check. Few people use them and I cannot confirm they work on other machines, so they are not in this item. If you want to try it, see github.com/kudachou/barotrauma-mod-manager/releases - the installer whose filename does not contain workshop is the full edition, and it needs your own Steam Web API key.
